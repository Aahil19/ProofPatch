    Evaluation contract

    What “verified” means here.

    1. 01
      Observe a real failure

      The selected pytest suite must execute and report at least one failing node ID.

    2. 02
      Reproduce before editing

      The same node IDs must fail again on an untouched copy of the repository.

    3. 03
      Verify the candidate

      Formerly failing tests pass and the selected regression suite retains every test identity.

    4. 04
      Escalate uncertainty

      Two failed candidates stop safely with logs, diffs, and reasons for a human reviewer.

    Read this result correctly.

    The repair candidates in this benchmark are scripted fixtures. The comparison measures the value of reproduction, verification feedback, bounded retries, and escalation. It is not a claim about any language model’s repair accuracy. LLM cost is therefore $0 for both systems.
